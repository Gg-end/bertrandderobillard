# bertrandderobillard.org

Site statique (HTML/CSS, sans dépendance).

- `content/*.html` : le contenu de chaque page (à modifier)
- `template.html` : structure commune (en-tête, menu, pied de page)
- `assets/` : styles et images (ajouter `portrait.jpg`)
- `python3 build.py` : régénère les pages `.html` à la racine

## Publication gratuite avec GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
Domaine personnalisé : saisir `bertrandderobillard.org` dans Pages, puis configurer le DNS chez le registrar.
